<h1>The project description</h1>
This is a sample API I made in two days, the frontend was downloaded from another git repository
The project can be downloaded for custom usage, but you have to get your own public and private API keys. The project dependencies are listed in the project file (in .toml format). If you want to run the app just type:
<ul>
    <li>"uv run streamlit run frontend.py" to run the frontend</li>
    <li>"uv run .\main.py" to run the backend server for the application to work</li>
</ul>
You also need to run both processes in two seperate terminals for this to work, this is just an API not a full stack web application. Currently I'm still learningand right now I'm learning about REST APIs and CRUD operations. All projects will be put in a portfolio, but for now the portfolio is not ready. I suggest make your own .env file for this project if you wish to use it.
