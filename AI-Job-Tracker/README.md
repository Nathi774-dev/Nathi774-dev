# This project is unfinished and still requires some improvements
So far it is a portfolio ready project even though their are still unfinised features such as:
- AI integration
- Proper scheduling
- More fluid designs

To start the project in your local environment please:
- run "npm run dev" after you have accessed the frontend folder in your terminal
- run "uvicorn app.main:app --reload" in the backend folder
- you will also need postgres sql installed on your computer, and past your own link
  in the environment file in the root of the project.
